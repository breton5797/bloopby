2. 웹판: 주간 랭킹·클라우드 저장·이용 기록

2-1. 기본 웹판 주소 (https://breton5797.github.io/bloopby/)

기본 웹판은 로그인 없이 익명으로 동작하며, 아래 정보를 운영자가 이용하는 서버(Supabase, 대한민국 서울 리전)로 보냅니다. 이름·이메일·광고 ID·위치는 보내지 않습니다. 서버에 연결할 수 없으면 기능만 꺼지고 게임은 기기 안 저장으로 계속 동작합니다.

기능보내는 값보내는 시점누가 볼 수 있나
주간 랭킹기기 ID, 토큰 해시, 이번 주 구분 값(주 번호), 점수(주간 최고점만 보관), 익명 닉네임(예: "#1234" — 기기 ID로 만든 4자리 번호)과 선택한 캐릭터무한 모드 게임오버 시 점수가 0보다 클 때 자동 등록(스테이지 모드는 등록 안 함)기본 웹판으로 게임을 여는 모든 이용자에게 공개. 랭킹 화면(상위 50명)에는 "플레이어 #1234", 캐릭터, 점수만 보이고 기기 ID는 보이지 않음. 지난주 순위 보상 계산에도 쓰임

2-2. claude.ai 공유 링크

아래 내용은 같은 게임을 claude.ai 공유 링크로 열었을 때에만 해당합니다. 이때는 2-1장의 운영자 서버(Supabase)로 아무것도 보내지 않으며 이용 기록도 수집하지 않습니다.

웹판은 claude.ai의 아티팩트 공유 링크로 제공됩니다. claude.ai에 로그인한 상태로 플레이할 때만 아래 정보가 claude.ai 플랫폼(운영: Anthropic)의 아티팩트 저장소에 저장됩니다. 로그인하지 않았거나 플랫폼이 사용자 ID를 주지 않으면 이 기능은 자동으로 꺼지고, 진행 데이터는 기기 안에만 남습니다.

기능저장되는 값저장 시점누가 볼 수 있나
주간 랭킹플랫폼이 주는 사용자 ID(문서 이름), 이번 주 최고 점수, 지금까지 등록한 최고 점수, 선택한 캐릭터, 갱신 시각, 이번 주·지난주 구분 값과 지난주 점수무한 모드 게임오버 시 점수가 0보다 크고 이번 주 기록을 넘을 때 자동 등록(스테이지 모드는 등록 안 함)같은 링크로 게임을 여는 다른 이용자에게 공개. 랭킹 화면(상위 50명)에는 사용자 ID로 만든 익명 닉네임(예: "플레이어 #1234"), 선택한 캐릭터, 점수가 보이며, claude.ai 프로필 이름은 다른 이용자에게 보이지 않습니다. 사용자 ID는 기록의 문서 이름으로 저장됩니다. 지난주 순위 보상 계산을 위해 다른 이용자의 게임도 사용자 ID와 점수를 읽습니다
클라우드 저장1장의 게임 진행 데이터 전체(설정 포함), 경험치, 저장 시각진행이 바뀔 때(최대 8초에 한 번)게임 화면에서 다른 이용자에게 보여 주지 않음. 플랫폼 안에서의 접근 범위는 claude.ai 정책을 따름
  • 운영자가 이 정보를 따로 내려받거나 다른 곳에 제공하지 않습니다. 저장소의 처리는 claude.ai(Anthropic) 개인정보처리방침을 따릅니다.
  • 원하지 않으면: claude.ai에서 로그아웃한 상태로 플레이하면 랭킹 등록과 클라우드 저장이 모두 일어나지 않습니다. 로그인 상태에서는 무한 모드 점수가 자동으로 랭킹에 등록되므로, 등록을 원하지 않으면 로그아웃 상태로 플레이해 주세요.
  • 이미 등록된 랭킹 기록이나 클라우드 저장을 지우려면 아래 문의처로 알려 주세요. 설정의 "저장 데이터 초기화"는 기기 데이터와 클라우드 저장을 초기 상태로 덮어쓰지만 랭킹 기록은 지우지 않습니다.

앱판(스토어)은 출시 빌드에서 랭킹·클라우드 저장 적용 여부를 확정한 뒤 이 방침에 먼저 반영합니다.

3. 보유·이용 기간

  • 기기 안 데이터: 이용자가 앱을 삭제하거나 설정의 "저장 데이터 초기화"를 실행하거나 브라우저 데이터를 지울 때까지.
  • 기본 웹판(운영자 서버): 이용 기록은 수집 후 최대 1년, 주간 랭킹 기록은 해당 주가 끝난 뒤 최대 1년, 클라우드 저장은 마지막 저장 후 1년간 갱신이 없으면 운영자가 삭제합니다. 서비스를 종료하면 함께 삭제하며, 삭제 요청을 받으면 지체 없이 지웁니다.
  • claude.ai 공유 링크 랭킹·클라우드 저장: 해당 공유 링크(아티팩트)가 유지되는 동안. 삭제 요청을 받으면 지체 없이 지웁니다. 공유 링크를 내리면 함께 사라집니다.
  • 광고·결제 제공사 데이터: 각 제공사의 방침에 따릅니다.

5. 광고와 동의

  • 웹판에는 광고가 없습니다.
  • 앱판은 보상형 광고만 사용하며 전면 광고는 사용하지 않습니다. 광고 제거 상품을 구매하면 광고 없이 보상을 받습니다.
  • 앱판에서 유럽경제지역·영국·스위스 이용자에게는 Google UMP 동의 창을, iOS에서는 앱 추적 투명성(ATT) 요청을 광고 동의와 별도로 보여 주며, 동의 전에는 광고를 요청하지 않습니다(출시 빌드에서 구현·검증 예정).
  • 기기의 광고 ID 설정에서 맞춤 광고를 끌 수 있습니다.

6. 아동·청소년

서비스는 만 14세 미만 아동을 주 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다. 만 14세 미만 아동의 개인정보가 수집된 사실을 알게 되면 지체 없이 삭제합니다. 기본 웹판의 랭킹·클라우드 저장·이용 기록은 로그인 없이 무작위 기기 ID로만 동작하며, 이름 등 직접 입력하는 정보나 자유 입력 닉네임을 받지 않습니다. claude.ai 공유 링크의 랭킹과 클라우드 저장은 claude.ai 계정으로 로그인한 경우에만 동작하며, claude.ai 계정의 이용 연령 제한이 적용됩니다. 앱으로 출시할 때는 스토어 대상 연령과 연령 확인 방식을 이 방침에 추가합니다.

7. 이용자의 권리

  • 기기 안 데이터: 앱 삭제 또는 설정 > 저장 데이터 초기화로 직접 지울 수 있습니다.
  • 기본 웹판의 랭킹·클라우드 저장·이용 기록: 아래 이메일로 열람·정정·삭제·처리정지를 요청할 수 있습니다. 설정 화면에 보이는 기기 ID(앞 8자리)를 함께 알려 주세요.
  • claude.ai 공유 링크의 랭킹·클라우드 저장: 아래 이메일로 요청할 수 있습니다. 본인 확인을 위해 랭킹에 보이는 익명 닉네임(예: 플레이어 #1234)과 대략적인 기록 시점을 알려 주세요.
  • 광고·결제 제공사가 가진 정보에 대한 요청은 해당 제공사로 하시거나 아래 문의처로 알려 주세요.

8. 안전성 확보 조치

운영자는 수집 항목을 무작위 기기 ID와 게임 데이터로 최소화하며, 모든 통신은 HTTPS를 사용합니다. 기본 웹판의 서버(Supabase)는 행 단위 접근 제어(RLS)로 게임이 이용 기록을 추가만 할 수 있게 하고, 랭킹·클라우드 저장은 토큰을 확인하는 서버 함수로만 읽고 쓰며, 토큰은 해시(SHA-256)로만 저장합니다. 게임에는 공개용(anon) 키만 들어 있고 관리자 키는 넣지 않습니다. claude.ai 공유 링크 저장소의 보안은 claude.ai 플랫폼이 제공합니다.

2. Web build: weekly ranking, cloud save and usage events

2-1. Main web address (https://breton5797.github.io/bloopby/)

The main web build works anonymously with no sign-in and sends the data below to the server we use (Supabase, Seoul, South Korea region). It never sends your name, email, advertising ID or location. If the server cannot be reached, these features simply switch off and the game keeps working with on-device saves.

2-2. claude.ai share link

The section below applies only when the same game is opened through the claude.ai share link. In that case nothing is sent to our server (Supabase) from section 2-1 and no usage events are collected.

The web build is served as a claude.ai artifact share link. Only when you play while signed in to claude.ai is the following stored in the artifact storage of the claude.ai platform (operated by Anthropic). If you are not signed in, or the platform provides no user ID, these features switch off and your progress stays on your device only.

3. Retention

  • On-device data stays until you uninstall the app, use Settings > Reset save data, or clear browser data.
  • Main web address (our server): we delete usage events at most 1 year after collection, weekly ranking entries at most 1 year after their week ends, and cloud saves after 1 year without an update. Everything is deleted if the service ends, and without delay on request.
  • claude.ai share-link ranking and cloud save: for as long as the share link (artifact) exists. We delete them without delay on request, and they are removed if the share link is taken down.
  • Data held by ad and billing providers follows their own policies.

5. Ads and consent

  • The web build has no ads.
  • The app build uses rewarded ads only, never interstitials. Buying Remove Ads gives rewards without ads.
  • In the app build, users in the EEA, UK and Switzerland see a Google UMP consent prompt; on iOS an App Tracking Transparency prompt is shown separately from ad consent. No ad is requested before consent (to be implemented and verified in the store build).
  • You can turn off personalised ads in your device's advertising ID settings.

6. Children

The Game is not directed to children under 14 (Korea) or under 13 (US), and we do not knowingly collect their personal data. If we learn we have, we delete it without delay. On the main web address, the ranking, cloud save and usage events work only with a random device ID; we never ask for a name or any free-text nickname. On the claude.ai share link, the weekly ranking and cloud save work only when you are signed in with a claude.ai account, which has its own age requirements. When the Game is released as an app, we will add its store target age and age-check method to this policy.

7. Your rights

  • On-device data: delete it yourself (uninstall, or Settings > Reset save data).
  • Main web address ranking, cloud save and usage events: email us to access, correct, delete or stop processing them. Include the device ID shown in Settings (first 8 characters).
  • claude.ai share-link ranking and cloud save: email us. To help us find your entry, tell us the anonymous nickname shown on the ranking (e.g. Player #1234) and roughly when you played.
  • For data held by ad or billing providers, contact them or write to us below.

8. Security

We limit what we collect to a random device ID and game data, and all network calls use HTTPS. On the main web build's server (Supabase), row-level security lets the game only add usage events; the ranking and cloud save are read and written only through server functions that check your token, and the token is stored only as a SHA-256 hash. The game contains only the public (anon) key, never an admin key. Security of the claude.ai share-link storage is provided by the claude.ai platform.
