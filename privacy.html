BLOOPBY 블룹비 개인정보처리방침

시행일: 2026-11-18

미니멀코리아(이하 "운영자")는 BLOOPBY 블룹비: 심해 대탈출(이하 "서비스")을 이용하는 분의 개인정보를 소중히 다루며, 개인정보 보호법 등 관련 법령을 지킵니다.

1. 수집하는 정보와 이용 목적

운영자는 회원가입을 받지 않으며 이름, 이메일, 전화번호, 위치를 직접 수집하지 않습니다.

2. 웹판(claude.ai 공유 링크): 클라우드 저장과 주간 랭킹

기본 웹판 주소(https://breton5797.github.io/bloopby/, GitHub Pages)에서는 주간 랭킹과 클라우드 저장이 동작하지 않으며, 진행 데이터는 기기 안에만 저장됩니다. 아래 내용은 같은 게임을 claude.ai 공유 링크로 열었을 때에만 해당합니다.

웹판은 claude.ai의 아티팩트 공유 링크로 제공됩니다. claude.ai에 로그인한 상태로 플레이할 때만 아래 정보가 claude.ai 플랫폼(운영: Anthropic)의 아티팩트 저장소에 저장됩니다. 로그인하지 않았거나 플랫폼이 사용자 ID를 주지 않으면 이 기능은 자동으로 꺼지고, 진행 데이터는 기기 안에만 남습니다.

기능저장되는 값저장 시점누가 볼 수 있나
주간 랭킹플랫폼이 주는 사용자 ID(문서 이름), 이번 주 최고 점수, 지금까지 등록한 최고 점수, 선택한 캐릭터, 갱신 시각, 이번 주·지난주 구분 값과 지난주 점수무한 모드 게임오버 시 점수가 0보다 크고 이번 주 기록을 넘을 때 자동 등록(스테이지 모드는 등록 안 함)같은 링크로 게임을 여는 다른 이용자에게 공개. 랭킹 화면(상위 50명)에는 사용자 ID로 만든 익명 닉네임(예: "플레이어 #1234"), 선택한 캐릭터, 점수가 보이며, claude.ai 프로필 이름은 다른 이용자에게 보이지 않습니다. 사용자 ID는 기록의 문서 이름으로 저장됩니다. 지난주 순위 보상 계산을 위해 다른 이용자의 게임도 사용자 ID와 점수를 읽습니다
클라우드 저장1장의 게임 진행 데이터 전체(설정 포함), 경험치, 저장 시각진행이 바뀔 때(최대 8초에 한 번)게임 화면에서 다른 이용자에게 보여 주지 않음. 플랫폼 안에서의 접근 범위는 claude.ai 정책을 따름
  • 운영자가 이 정보를 따로 내려받거나 다른 곳에 제공하지 않습니다. 저장소의 처리는 claude.ai(Anthropic) 개인정보처리방침을 따릅니다.
  • 원하지 않으면: claude.ai에서 로그아웃한 상태로 플레이하면 랭킹 등록과 클라우드 저장이 모두 일어나지 않습니다. 로그인 상태에서는 무한 모드 점수가 자동으로 랭킹에 등록되므로, 등록을 원하지 않으면 로그아웃 상태로 플레이해 주세요.
  • 이미 등록된 랭킹 기록이나 클라우드 저장을 지우려면 아래 문의처로 알려 주세요. 설정의 "저장 데이터 초기화"는 기기 데이터와 클라우드 저장을 초기 상태로 덮어쓰지만 랭킹 기록은 지우지 않습니다.

앱판(스토어)에는 이 기능이 없습니다. 자체 서버 랭킹을 도입하면 저장 항목과 보관 기간을 이 방침에 먼저 반영합니다.

3. 보유·이용 기간

  • 기기 안 데이터: 이용자가 앱을 삭제하거나 설정의 "저장 데이터 초기화"를 실행하거나 브라우저 데이터를 지울 때까지.
  • 웹판 랭킹·클라우드 저장: 해당 공유 링크(아티팩트)가 유지되는 동안. 삭제 요청을 받으면 지체 없이 지웁니다. 공유 링크를 내리면 함께 사라집니다.
  • 광고·결제 제공사 데이터: 각 제공사의 방침에 따릅니다.

4. 제3자 제공·처리 위탁

운영자는 개인정보를 판매하지 않으며, 법령에 근거가 있는 경우를 제외하고 제3자에게 제공하지 않습니다. 서비스 제공을 위해 다음 사업자의 기능을 이용합니다.

5. 광고와 동의

  • 웹판에는 광고가 없습니다.
  • 앱판은 보상형 광고만 사용하며 전면 광고는 사용하지 않습니다. 광고 제거 상품을 구매하면 광고 없이 보상을 받습니다.
  • 앱판에서 유럽경제지역·영국·스위스 이용자에게는 Google UMP 동의 창을, iOS에서는 앱 추적 투명성(ATT) 요청을 광고 동의와 별도로 보여 주며, 동의 전에는 광고를 요청하지 않습니다(출시 빌드에서 구현·검증 예정).
  • 기기의 광고 ID 설정에서 맞춤 광고를 끌 수 있습니다.

6. 아동·청소년

서비스는 만 14세 미만 아동을 주 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다. 만 14세 미만 아동의 개인정보가 수집된 사실을 알게 되면 지체 없이 삭제합니다. 웹판의 주간 랭킹과 클라우드 저장은 claude.ai 계정으로 로그인한 경우에만 동작하며, claude.ai 계정의 이용 연령 제한이 적용됩니다. 앱으로 출시할 때는 스토어 대상 연령과 연령 확인 방식을 이 방침에 추가합니다.

7. 이용자의 권리

  • 기기 안 데이터: 앱 삭제 또는 설정 > 저장 데이터 초기화로 직접 지울 수 있습니다.
  • 웹판 랭킹·클라우드 저장: 아래 이메일로 열람·정정·삭제를 요청할 수 있습니다. 본인 확인을 위해 랭킹에 보이는 익명 닉네임(예: 플레이어 #1234)과 대략적인 기록 시점을 알려 주세요.
  • 광고·결제 제공사가 가진 정보에 대한 요청은 해당 제공사로 하시거나 아래 문의처로 알려 주세요.

8. 안전성 확보 조치

운영자는 자체 서버에 개인정보를 저장하지 않는 구조로 위험을 줄이며, 외부 통신은 HTTPS를 사용합니다. 웹판 저장소의 보안은 claude.ai 플랫폼이 제공합니다. 운영 서버를 도입하면 접근 통제·암호화 등 조치를 추가하고 방침에 명시합니다.

2. Web build (claude.ai share link): cloud save and weekly ranking

On the main web address (https://breton5797.github.io/bloopby/, GitHub Pages) the weekly ranking and cloud save do not run, and your progress is stored only on your device. The section below applies only when the same game is opened through the claude.ai share link.

The web build is served as a claude.ai artifact share link. Only when you play while signed in to claude.ai is the following stored in the artifact storage of the claude.ai platform (operated by Anthropic). If you are not signed in, or the platform provides no user ID, these features switch off and your progress stays on your device only.

3. Retention

  • On-device data stays until you uninstall the app, use Settings > Reset save data, or clear browser data.
  • Web ranking and cloud save: for as long as the share link (artifact) exists. We delete them without delay on request, and they are removed if the share link is taken down.
  • Data held by ad and billing providers follows their own policies.

5. Ads and consent

  • The web build has no ads.
  • The app build uses rewarded ads only, never interstitials. Buying Remove Ads gives rewards without ads.
  • In the app build, users in the EEA, UK and Switzerland see a Google UMP consent prompt; on iOS an App Tracking Transparency prompt is shown separately from ad consent. No ad is requested before consent (to be implemented and verified in the store build).
  • You can turn off personalised ads in your device's advertising ID settings.

6. Children

The Game is not directed to children under 14 (Korea) or under 13 (US), and we do not knowingly collect their personal data. If we learn we have, we delete it without delay. On the web version, the weekly ranking and cloud save work only when you are signed in with a claude.ai account, which has its own age requirements. When the Game is released as an app, we will add its store target age and age-check method to this policy.

7. Your rights

  • On-device data: delete it yourself (uninstall, or Settings > Reset save data).
  • Web ranking and cloud save: email us to access, correct or delete them. To help us find your entry, tell us the anonymous nickname shown on the ranking (e.g. Player #1234) and roughly when you played.
  • For data held by ad or billing providers, contact them or write to us below.

8. Security

We reduce risk by not storing personal data on our own servers, and all network calls use HTTPS. Security of the web build's storage is provided by the claude.ai platform. If we introduce a server we will add access control and encryption and describe them here.
